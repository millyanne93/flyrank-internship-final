# AI-Powered Portfolio Chat Agent

A chat widget built into my portfolio that lets visitors ask questions about my
background, technical skills, projects, and experience, powered by Gemini 2.5 Flash.

## What it does

- Visitors can ask questions about my professional background directly on the site
- The agent answers using real information about my skills, projects, and experience
- Responses are generated by Gemini 2.5 Flash, called from a Netlify serverless function
- The agent is deliberately constrained; it won't answer questions outside my
  background, and it won't invent details it doesn't have

## Who it's for

- Recruiters and hiring managers researching my background
- Potential collaborators trying to understand my technical experience
- Anyone visiting my portfolio who wants a fast, conversational overview of my work

## Architecture

```
┌───────────────────────────┐
│  Portfolio website         │
│  HTML / CSS / JS           │
│  ── Chat widget ──         │
└─────────────┬─────────────┘
              │  HTTPS request
              │  (user's question)
              ▼
┌───────────────────────────┐
│  Netlify function           │
│                              │
│  1. Receives the question    │
│  2. Builds the system prompt │
│  3. Calls the Gemini API     │
│  4. Returns the response     │
└─────────────┬─────────────┘
              │  HTTPS
              ▼
┌───────────────────────────┐
│  Google Gemini API          │
│  Gemini 2.5 Flash            │
└───────────────────────────┘
```

The widget never talks to Gemini directly; every request goes through the Netlify
function first, so the API key stays server-side and the system prompt (the actual
guardrail) is enforced consistently on every call, not something the client could
bypass or override.

## System prompt design

The agent is deliberately constrained, on purpose, to keep it accurate and on-topic:

```
You are an AI assistant for Millyanne Wanjala's portfolio.

Your purpose is to answer questions about:
- Her professional background and experience
- Her technical skills and technologies used
- Her projects (PlanIt, EduAdapt, Trackr, Widget Platform, Image Matching Engine)
- Her education and certifications

Important rules:
- Only answer questions about Millyanne
- If you don't know something, say you don't know
- Do not invent projects, skills, or qualifications
- Politely decline unrelated questions
```

This is the whole guardrail:  a short, explicit instruction rather than any external
filtering layer. It's simple enough to read in one glance and verify by hand, which
matters more than it sounds: a guardrail I can't reason about isn't one I actually trust.

### Prerequisites (if reviewing the code locally)
- [Node.js](https://nodejs.org/) (v18+)
- A free [Netlify](https://www.netlify.com/) account
- A free [Gemini API key](https://aistudio.google.com/apikey) (Google AI Studio, no card)

### Local setup, for reference

**1. Install dependencies**
```bash
npm install
```

**2. Set up environment variables**
```bash
cp .env.example .env
# add your own GEMINI_API_KEY to .env
```

**3. Run locally with the Netlify CLI**
```bash
npx netlify dev
```
This serves the site and the serverless function together, so the chat widget behaves
exactly as it does in production.

**4. Deploy** (to your own Netlify account, with your own API key)
```bash
netlify deploy --prod
```
Set `GEMINI_API_KEY` as an environment variable in your Netlify site settings before
deploying — the function reads it from there in production, not from `.env`.

To actually try the agent, visit the live site instead: [the widget is in the
bottom-right corner](https://millyanne93-portfolio.netlify.app/).

## Evaluation results

| Metric | Result |
|---|---|
| Response time | 2–5 seconds |
| Accuracy | High, within the constrained scope |
| Hallucination rate | Low — the system prompt is designed specifically to prevent this |
| Off-topic refusal | Verified live in the demo video — declines unrelated questions correctly |
| Free tier limits | 15 requests/minute, 1,500 requests/day |

**What "accuracy" means here:** the agent was tested against a set of expected
questions (background, skills, specific projects, and deliberately off-topic
questions) and manually checked that each response was both factually correct and
appropriately scoped — declining anything outside my background rather than
guessing or fabricating an answer.

## Limitations

| Limitation | Description | Why it exists |
|---|---|---|
| No conversation persistence | Chat history resets on page refresh | Simpler implementation; no database needed for a portfolio site |
| No rate limiting | A traffic spike could exhaust the free-tier API quota | Traffic on a personal portfolio is low enough that this hasn't been a real risk yet |
| Narrow knowledge scope | Only answers questions about me | Intentional — this is what keeps hallucination risk low |
| Free tier only | Could hit limits under sustained high traffic | Free tier comfortably covers realistic portfolio traffic |
